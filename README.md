# Legion: Ultimate Assistant (v11.2.0)

QoL-аддон (UserScript) для браузерной игры **Legion** (play.multidonate.ru). 
Добавляет удобный интерфейс, умный чат и помощников, не нарушая баланс игры. 

## ✨ Основные возможности

*   **💬 Умный чат:** Кастомный виджет с вкладками (Город/Шахта/ЛС), поддержкой выноса в отдельное окно (PiP), кликабельными никами и историей личных сообщений.
*   **🏛️ Сканер Аукциона:** Поиск выгодных лотов, расчет скидки от официальной цены магазина, фильтры по редкости и классам.
*   **👥 Разведка (Игроки):** Отслеживание онлайна (кто в городе, кто в шахте), быстрый доступ к досье игрока, лотам и обмену.
*   **🏰 Карманный Город:** Открытие нативных зданий игры (Аукцион, Лавка, Кузня, Тренер, Склад) из любой локации.
*   **🧮 Планировщик билдов:** Дерево навыков с симуляцией статов для всех классов.
*   **🛡️ Стелс-режим:** Защита от определения фоновой вкладки при нахождении в шахте.

## 🚀 Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) для вашего браузера.
2. Нажмите на ссылку ниже, чтобы установить скрипт:
   **[Установить Legion Ultimate Assistant](https://raw.githubusercontent.com/Eciell/Legion-Ultimate-Assistant/main/dist/LegionUltimate.user.js)**
3. Подтвердите установку в Tampermonkey.
4. Обновления будут приходить автоматически (через `@updateURL`).

## 🛠️ Для разработчиков (Local Development)

Проект собирается из модулей в папке `src/` в единый файл `dist/LegionUltimate.user.js`.

**Быстрый старт:**
```bash
npm install
npm run build:ultimate  # Сборка публичной версии (для Tampermonkey)
npm run check           # Проверка синтаксиса готового файла
