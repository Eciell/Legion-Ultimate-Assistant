# Legion: Ultimate Assistant (v11.7.1)

QoL-аддон (UserScript) для браузерной игры **Legion** (legiongame.gg). 
Добавляет удобный интерфейс, помощников и групповые инструменты, не нарушая баланс игры. 

## ✨ Основные возможности

*   **⚙️ Планировщик Героя:** 
    *   *Вкладка «Билды»:* Симуляция статов для всех классов с точным отображением цифр навыков. Поддерживает сохранение и загрузку нескольких сборок (в `localStorage`), обмен билдами через короткие Base64-ссылки. Учитывает мультиэффекты талантов и вершины веток, шанс избежать яда/тины, механические флаги без лишних `%`, а `critX` считается с учётом `hero.xs`.
    *   *Индекс билда ⓘ:* Внутренняя оценка сборки Legion Ultimate (веса статов + заточка) с полной расшифровкой в тултипе. Рядом показывается нативный **«Рейтинг игры ⚔»** (`hero.power`), если сервер его прислал; индекс и рейтинг не подменяют друг друга.
    *   *Вкладка «Примерка»:* Сравнение текущей экипировки с выбранной сборкой по слотам — с цветовой индикацией дельты характеристик и заточки (зелёный/красный).
    *   *Вкладка «Заточка»:* Калькулятор стоимости и характеристик. Поиск предметов по инвентарю (Надето/Сумка/Склад), расчет с учетом звезд и сфер. Корректно учитывает деление бонуса на 4 для процентных статов (крит, уклонение и т.д.).
*   **🏛️ Сканер Аукциона:** Поиск выгодных лотов, расчет скидки от официальной цены магазина, фильтры по редкости и классам, отображение реальных артов предметов. Пагинация по 50 лотов, история цен (иконка 📊), избранное (звездочка), фильтр «Мои лоты», сравнение с ценой NPC, оповещения о выгодных лотах и колонка «Вложено» (стоимость заточки).
*   **👥 Разведка (Игроки):** Отслеживание онлайна (кто в городе, кто в шахте), быстрый доступ к досье игрока, лотам и обмену.
*   **🏰 Карманный Город:** Открытие нативных зданий игры (Аукцион, Лавка, Заточка, Тренер, Склад, Кузня, Звездочёт, Гильдия) из любой локации.
    *   *Режим закрепа 📌:* Кнопка в шапке окна сворачивает его в компактный перетаскиваемый мини-виджет с быстрым доступом ко всем 8 зданиям. Позиция и состояние закрепа сохраняются в `localStorage` и восстанавливаются при следующем запуске.
*   **📯 Уведомления о сборах на элитных монстров:** Настраиваемая плашка о чужих сборах гильдии/округа с кнопкой «Присоединиться» (по умолчанию выключена). Размер плашки — `S / M / L`, размещается над нижним рядом кнопок навигации. Рядом в настройках — автоскип боёв с обычными и элитными монстрами (нативными кликами, без сетевых запросов).
*   **🛡️ Партия (Пати):**
    *   *Создание и вход:* Создавайте группу и приглашайте друзей по уникальному «Коду приглашения». Вход — одним кликом.
    *   *Управление:* Владелец пати может кикать участников, перевыпускать код (если он утёк) или распускать группу. При выходе владельца пати расформировывается.
    *   *HP-панель:* На экране появляется плавающая панель со здоровьем всех участников пати. Её можно перетаскивать мышкой в любое место, позиция сохраняется. Карточки участников обновлены: компактная вёрстка, статусы и читаемые полоски HP.
    *   *Чат пати 💬:* Встроенная сворачиваемая панель **«ЧАТ ПАТИ»** в HUD группы. Обновляется в реальном времени (опрос каждые 3.5 с + мгновенная синхронизация при возврате фокуса на окно), показывает счётчик непрочитанных. История живёт **только в оперативной памяти сервера (RAM)** и не пишется в SQLite — после перезапуска сервера лента начинается заново.
    *   *Синхронизация:* Полоски HP союзников обновляются сразу после ответа игры (`/api/me`, `/api/qact`), плюс страховочный тик раз в 30 секунд. Видно, кто ранен, кто в походе, кто умирал.
*   **❤️ Взаимный хил (для Жрецов):** Если ваш персонаж — Жрец, рядом с ранеными союзниками в HP-панели появляется кнопка ❤. Один клик — и команда `лечить @ник` **копируется в буфер обмена** (без автовставки в чат похода: остаётся вставить её самостоятельно и отправить). Такой вариант безопаснее и не зависит от фокуса игрового поля.
*   **📜 Журнал боя:** Под HP-панелью — сворачиваемый «Журнал», в который пишутся важные события: вход/выход из похода, смерти, полученный урон (красный), хил (зелёный) и успешные касты лечения от союзников.
*   **💛 Благодарность:** В футере меню аддона — окно со списком людей, которые помогли проекту баг-репортами и идеями. Кнопка «Аддон» (FAB) управляется единым контроллером и может жить как плавающий кружок или в нативном нижнем меню игры.
*   **🛡️ Безопасность:** Отсутствие подмены браузерных свойств (античит-френдли).


## 🚀 Установка

Для работы скрипта вам понадобится браузер на движке Chromium (Chrome, Edge, Opera, Яндекс.Браузер) или Firefox, а также установленное расширение **Tampermonkey**.

### Шаг 1. Установите Tampermonkey
*   [Tampermonkey для Chrome](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
*   [Tampermonkey для Firefox](https://addons.mozilla.org/ru/firefox/addon/tampermonkey/)
*   [Tampermonkey для Edge](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)

### Шаг 2. Включите режим разработчика (ТОЛЬКО для Chrome / Яндекс / Edge / Opera)
> ⚠️ **Важно!** Современные браузеры на движке Chromium блокируют работу пользовательских скриптов без специального разрешения. Если пропустить этот шаг, скрипт установится, но **не будет работать**.

1. Откройте страницу управления расширениями (введите в адресную строку):
   * Chrome/Яндекс: `chrome://extensions/`
   * Edge: `edge://extensions/`
   * Opera: `opera://extensions/`
2. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
   *(В Chrome и Яндексе, и возможно Edge нужно зайти в «Детали» расширения Tampermonkey и включить переключатель **«Разрешить пользовательские скрипты»**, **Для Firefox:** этот шаг делать не нужно, там скрипты работают из коробки.).*

### Шаг 3. Установите скрипт
Нажмите на ссылку ниже — Tampermonkey перехватит страницу и предложит установить аддон:
👉 **[Установить Legion Ultimate Assistant](https://raw.githubusercontent.com/Eciell/Legion-Ultimate-Assistant/main/dist/LegionUltimate.user.js)**

Нажмите «Установить» (Install) во вкладке, которая откроется.

### Шаг 4. Проверка
Зайдите на `legiongame.gg`. В правом нижнем углу экрана должен появиться перетаскиваемый кружок с котиком 🐱 — это меню аддона. Обновления будут приходить автоматически.

## 🛠️ Для разработчиков (Local Development)

Проект собирается из модулей в папке `src/` в единый файл `dist/LegionUltimate.user.js`.

**Быстрый старт:**
```bash
npm install
npm run build:ultimate
npm run check
```
